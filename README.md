# deepseek webui

一个跑在浏览器里的、带 Markdown 渲染和流式输出的高级终端。
界面照着 OpenAI Codex CLI / Warp 那种"开发者工作台"来做——不是聊天气泡。

```
┌────────────────────────────────────────────────────────────────┐
│ ◉ deepseek-flash   会话标题          ↑1.2k ↓847  02:14  ⌘K  ⚙ │ ← 状态栏 + 底部绿线
├────────────────────────────────────────────────────────────────┤
│ ❯ 你的问题                                                     │
│ ────────────────────────────────────────────────────────────── │
│ ◉ ▸ 💭 Thought for 4.2s                        ← 折叠的思考过程 │
│   正文（Markdown / 代码块 / 公式 / 表格 / diff）               │
│   ⧉ ↻ 👍 👎                      4.2s · 1,247 tokens           │
├────────────────────────────────────────────────────────────────┤
│ ❯ 输入点什么…                                    ＋  CHAT|AGENT │
│   Enter 发送 · Shift+Enter 换行 · Esc 中断 · Ctrl+K 命令面板    │
└────────────────────────────────────────────────────────────────┘
```

## 一、怎么启动 / 怎么停

**双击桌面上的「鲸语」图标**即可——**不会弹任何黑框**。

它的行为：
- 服务没在跑 → 在**后台**悄悄拉起来（隐藏窗口），等就绪后自动打开浏览器
- 服务已经在跑 → 只帮你开一个浏览器标签页，什么都不重启

| 想干什么 | 怎么做 |
|---|---|
| 打开聊天界面 | 双击桌面「鲸语」图标（或直接访问 `http://127.0.0.1:8765/`） |
| **停掉服务** | 双击项目里的 **`停止服务.bat`**（会告诉你停没停掉） |
| 看运行日志 | `data\server.log`（后台模式没有控制台，日志写这里） |
| 想看黑窗口调试 | 双击 `start.bat`（会显示控制台，能看到实时输出） |
| 手动启动 | `cd /d E:\deepseek-webui` 然后 `python server.py` |

> 服务只在你双击图标后才启动（**没有设开机自启**）。它常驻约 70MB 内存，
> 用记事本看 `data\server.log` 能查到启动记录和报错。

## 二、界面速查

| 想干什么 | 怎么做 |
|---|---|
| 新会话 | `Ctrl+N`，或命令面板里选 new |
| 切换 / 搜索会话 | `Ctrl+K`（↑↓ 选、Enter 开、Esc 关） |
| 中断生成 | `Esc`，或生成中按 `Ctrl+C`（没选中文字时） |
| 换模型 | 命令面板外的 `/model deepseek-v4-pro`，或设置面板 |
| 切主题 | `/theme dark` / `black` / `light`，或设置面板 |
| 加附件 | 点 `＋`、拖文件进来、`Ctrl+V` 粘贴截图、或 `/attach 完整路径` |
| 导出 | `/export`（单个会话）、设置面板里「导出全部」 |
| 看全部命令 | 输入框打 `/`（会弹出命令面板） |

斜杠命令：`/new` `/agent` `/chat` `/model` `/clear` `/settings` `/attach` `/export` `/theme` `/help`

## 三、聊天模式 vs 干活模式

输入框右边有个 `CHAT | AGENT` 开关，每个会话各自记着。

| | CHAT | AGENT |
|---|---|---|
| 背后是谁 | DeepSeek 聊天接口 | **Claude Code**（跟终端里那个是同一个） |
| 能干什么 | 回答问题、写代码给你看 | **直接读/改你电脑上的文件、跑命令、联网查** |
| 花多少 | 一句话几十 tokens | 一句话 3 万 tokens 起步 |
| 适合 | 问知识、解释概念、改文字 | "把 E:\xxx 那个脚本的报错修好" |

AGENT 会把每一步显示成终端日志：`▸ 读文件 E:\...`、`▸ 跑命令 ...`，点一下展开看输出，
被拒绝的工具会显示红色的 `⛔ ... 被拒绝`。

**不需要选工作目录**——起始目录在设置里（默认 `E:\`），它只是个落脚点，不是沙箱；
你在消息里写完整路径，它照样能访问任何盘。想保险就在设置里勾「只读模式」（实测能挡住，连绕道用 MATLAB 工具写文件都被拦了）。

## 四、附件（文档 / 图片 / 录音 / 视频）

**能在本地解析的都在本地解析（不花钱）**，只有语音转文字要调外部服务（复用你已有的硅基流动 key）。

| 类型 | 怎么处理 |
|---|---|
| 图片 png/jpg/webp/gif | 直接交给 `deepseek-flash` 看 |
| PDF | 先用 PyMuPDF 抽文字；**扫描件自动渲染成图**交给视觉模型读 |
| Word / Excel / PPT | 本地抽文本 + 表格（Excel 转成 `列 | 列` 文本） |
| txt / md / csv / json / 代码 | 直接读 |
| 录音 mp3/wav/m4a… | 走**硅基流动 ASR**（SenseVoiceSmall）转成文字，中文很准 |
| 视频 mp4/mkv/mov… | **ffmpeg 抽 8 帧**（给视觉模型看）+ **音轨转写** |

细节：
- 附件的解析结果会显示成终端风标签：`📄 论文.pdf 12 页，抽出 8,432 字`
- 注入模型的内容有上限（默认 4 万字/次），超了会截断并告诉你
- 一次最多塞 8 张图（扫描件页 / 视频帧）
- 设置面板底部会显示各项能力是否就绪（语音转写 / 视频处理 / 干活模式）

**装的东西**（都已装好）：`pip install pymupdf python-docx openpyxl python-pptx`、`winget install Gyan.FFmpeg`

## 五、常见问题

**端口被占用？** 程序会自己从 8765 往后找。想指定：`python server.py --port 9000`。

**API 报错？** 界面会在输入框上方用红条显示中文原因 + 怎么办。常见：
- 余额不足 → 去 platform.deepseek.com 充值
- 回答被截断 → **思考过程也占 max_tokens**，去设置里调大
- 连不上 → 如果开着 VPN/代理，关掉试试（DeepSeek 是国内服务）

**怎么换 API Key？** 设置面板里填（**存到后端 config.json，浏览器不回显明文**），
或改 `config.json`，或设环境变量 `DEEPSEEK_API_KEY`（优先级最高）。
不填的话会自动复用 Claude Code 那把 key。

**改主题色？** `static/style.css` 最上面，三套主题各有一份 `--green` / `--cyan`。

**数据和备份在哪？** `data/conversations/*.json`（会话）、`data/files/`（附件原件+解析结果）、
`data/images/`（图片）。浏览器 localStorage 也存一份，两边自动合并。

**页面样式不对/白屏？** `F5` 刷新。还不行就看浏览器控制台（F12）——页面里的错误会直接显示成红色提示条。

## 七、已知限制

1. **图片只有 `deepseek-flash` 能读**（`deepseek-v4-pro` 实测会无视图片）
2. **模型名不能带 `[1M]` 后缀**——那个只在 Claude Code 用的 Anthropic 端点有效
3. **思考过程占用 max_tokens**，所以长回答容易被截断（被截断时界面会提示）
4. 一次最多 8 张图；附件注入正文上限 4 万字（都可在 server.py 顶部调）
5. 视频是"抽帧+转录"式理解，不是逐帧原生理解。要真·视频理解得接阿里云百炼 qwen-vl 之类
6. 服务只绑 `127.0.0.1`，**没有登录**，别改成 `0.0.0.0`（那等于把电脑交给同网络的人）

## 说明

- 这是个**自用工具**，不是产品。代码按"能跑、看得懂"写的，没有测试和 CI。
- 应用图标用的是 **DeepSeek 官方 logo**（`static/deepseek-logo.svg`），版权归 DeepSeek 所有，这里仅作本地个人工具的标识使用。
- 前端渲染库（marked / highlight.js / KaTeX）不入库，由 `install_assets.py` 从 CDN 下载到 `static/vendor/`。
- 兼容的 API：任何 OpenAI 格式的 `/chat/completions`（改 `config.json` 的 `base_url` 即可换供应商）。
