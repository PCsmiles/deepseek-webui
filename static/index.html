欢迎使用 deepseek 本地工作台三步就能用起来

    

    

      
1

        直接开问
Enter 发送，Shift+Enter 换行，Esc 中断。
API Key 已经自动接上了，不用配置。

      
2

        要它动你电脑，就切到 AGENT
右上角的 CHAT | AGENT 开关。AGENT 模式下它能读写文件、跑命令，
        每一步都会显示成卡片；改完还能在顶栏的 Git 按钮里一键回滚。

      
3

        贴图、丢文档都行
Ctrl+V 粘贴截图、拖文件进来。PDF / Word / Excel / 录音 / 视频都会在本地解析。

      
⌘ Ctrl+K 是万能入口：搜索会话、接管你在终端里的对话、跑斜杠命令
