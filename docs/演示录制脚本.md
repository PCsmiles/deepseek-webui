# 演示动图录制脚本（20~30 秒）

README 顶部那张动图是"路人 3 秒内决定去留"的关键。这份是照着录的分镜，录完丢给 Claude 压成 GIF 并贴进 README 顶部。

---

## 一、录之前（3 分钟）

1. **清场**：把侧栏里你自己的会话删掉或新建几个演示会话——**别把私人聊天标题录进去**（姓名、学校、项目名）
2. **窗口**：浏览器窗口调成 **1500 × 950** 左右（或最大化），关掉无关标签页，避免弹通知
3. **录屏工具**（二选一）：
   - `Win + G` → Xbox Game Bar → 录屏（出 mp4，最省事；录完把 mp4 放到 `E:\` 并告诉 Claude）
   - **ScreenToGif**（免费）→ 直接出 gif，帧率设 10~12，宽度 1000~1200
4. 提前把要用的东西准备好：`E:\git练习\`（演示干活）、一张图片或一个 PDF（演示附件）

## 二、分镜（照着做，别解释，纯操作）

| 时间 | 画面 | 操作 |
|---|---|---|
| 0-4s | **质感**：CHAT 模式下流式出代码 | 输入「用 Python 写个读 CSV 算平均分的函数」，回车，让它流完（代码高亮 + 表格） |
| 4-10s | **杀手锏**：网页驱动 Claude Code | 切 **AGENT**，输入「看看 E:\git练习 里有什么文件」，回车 → 三张工具卡片（找文件/读文件/跑命令）按类型上色依次弹出 |
| 10-15s | **余额**：点开明细卡片 | 左键点侧栏余额 → 弹出卡片（蓝色气泡进度条 + 充值基准）→ Esc 关掉 |
| 15-21s | **附件**：本地解析，不花 API 钱 | 把图片/PDF **拖进输入框** → 出现附件条 → 提问 → 回答里引用到了附件内容 |
| 21-26s | **改代码看得见**：Git 面板 | 顶栏开 Git 面板 → 点一个文件看 diff（红绿）→ 关掉 |

## 三、录完

把文件（mp4 或 gif）放到 `E:\` 下，跟 Claude 说一声。它会：

```bash
# 压成适合 GitHub 的 GIF（12 帧、宽 1000、控制在 3MB 以内）
ffmpeg -i demo.mp4 -vf "fps=12,scale=1000:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" demo.gif
```

然后贴进 README 顶部（那里已经留好了取消注释就能用的位置）。
